# 前端视觉变体（2026-09-08）

基于 `docs/designs/liquidrag-style-v1.html`（定稿原型）派生的 3 个**视觉方向预览**，功能结构相同，只比观感。
浏览器打开任一文件即可预览（纯静态 HTML，无依赖）。

| 文件 | 方向 | 一句话 |
|---|---|---|
| `variant-a-bright-glass.html` | 明亮玻璃 | 背景更通透、气泡高亮、浅蓝主调，清爽的"浅色夜蓝" |
| `variant-b-modern-cards.html` | 现代卡片 | 深色工作台 + 面板/顶部状态条，层次清楚、信息密度高，偏生产力工具 |
| `variant-c-neon.html` | 霓虹夜航 | 深夜底 + 青紫霓虹描边/辉光/旋转渐变输入框，动感强 |
