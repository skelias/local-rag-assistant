知识库里关于 JWT 认证的最佳实践是什么？
✨

根据知识库中的文档，JWT 认证的核心要点：

1. 密钥管理 — 使用 RS256 非对称加密，私钥签名、公钥验签

2. Token 有效期 — Access Token 15 分钟，Refresh Token 7 天

3. 存储位置 — Access Token 存内存，Refresh Token 存 httpOnly Cookie
