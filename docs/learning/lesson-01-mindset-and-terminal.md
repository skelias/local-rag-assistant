# 第 1 课：心智模型 + 命令行

## 我们到底在做什么

做一个"住在你自己电脑上的 AI 知识问答助手"：你上传文档 → 电脑把文档整理成可搜索的知识库 → 你在网页提问 → 电脑先"查资料"再让云端 AI 基于资料回答。

```
浏览器(前端 UI)  ←API/SSE→  后端程序(FastAPI, Python)  ←API→  云端 AI(Claude/DeepSeek)
                                    │ 检索
                                    ▼
                              知识库(data/: SQLite + Qdrant 向量库)
```

## 必懂概念表（第 1 批）

| 词 | 一句话解释 | 比喻 |
|---|---|---|
| 前端 Frontend | 浏览器里你看到的界面（气泡、输入框） | 餐厅前厅/菜单 |
| 后端 Backend | 真正"干活"的程序：接收请求、检索、调 AI | 后厨 |
| API | 程序之间对话的固定窗口/接口 | 服务员传话的窗口 |
| 本地运行 | 软件跑在你自己的电脑上（127.0.0.1） | 自己家的厨房 |
| RAG | 检索增强生成：先查资料再让 AI 基于资料回答 | 先翻书再答题 |
| 知识库 | 上传的文档被切碎、向量化后存在 data/ 里 | 分类归档的图书馆 |
| 数据库 | 结构化存数据的地方（本项目用 SQLite） | 档案柜 |
| 服务器/端口 | 一个程序"蹲"在某地址某端口等人来问（127.0.0.1:8000） | 柜台 + 窗口号 |
| 命令行/终端 | 用文字命令指挥电脑的窗口 | 对电脑打字下令 |
| 当前目录 | 终端此刻"站在"哪个文件夹，命令在其内生效 | 你站在厨房哪个位置 |

## 附：新手排障卡（卡住时先看这里）

### 怎么打开终端
- 方法 A：按 `Win` 键 → 输入 `PowerShell` → 回车
- 方法 B：在项目文件夹的地址栏输入 `powershell` 后回车（会直接打开并站在该文件夹）
- 方法 C（装了 VS Code 后）：打开 VS Code → 菜单 终端 → 新建终端，或按 `Ctrl + ~`

### 怎么把结果贴给我
- 选中终端里的文字 → `Ctrl + C`（或右键→复制）→ 在对话里 `Ctrl + V` 粘贴
- 报错也一样：整段复制，别只截一部分

### 常见新手报错对照
| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| `python` 不是内部或外部命令 | Python 没装好或不在 PATH | 直接告诉我，我远程帮查（本项目环境里 python 是好的） |
| `cd : 无法找到路径…` | 目录名不对或路径含空格/中文 | 改用带引号：`cd "D:\RAG个人AI助手"`；也可以先 `dir D:\` 看看盘符下名字 |
| 粘贴命令没反应 | PowerShell 粘贴方式不同 | 点窗口内右键 = 粘贴；或 `Ctrl + V` |
| 中文显示成乱码 `锟斤拷` | 终端编码问题 | 敲 `chcp 65001` 回车换 UTF-8；不影响学习 |
| 命令输一半想重来 | — | `Ctrl + C` 取消当前输入，重新敲 |
